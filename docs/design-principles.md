# デザイン方針

このアプリのUIで守るルール。/ui-review で採用した修正方針がここに蓄積される。
新しい画面やコンポーネントを作るときも、このファイルに従うこと。

- ルールは「何をどうするか」を一行で書く（例: 一覧の区切りはカードではなく1pxの罫線）。
- 各ルールの末尾に由来の change 名を付ける。
- 例外を作るときは、ルールを消さずに例外として追記する。

## 形と区切り

- 同種のリンクの並びはカードではなく、1pxの罫線で区切る（ui-refine-home）
- 色の付いたアイコンタイルは使わない。ラベルと意味が重なるアイコンは置かない（ui-refine-home）
- ホバーで要素を浮かせない。変化は枠色か背景色で示す（ui-refine-home）
- 面は単色にし、グラデーションは使わない。塊の角丸は8px以下（ui-refine-home）

## 色と階層

- ブランド色は現在値とリンクに限る。長さの比較や線画アイコンには使わない（ui-refine-home）

## 余白とレイアウト

- スマホの初期表示で、画面を開く目的の操作（移動先のリンク）は折り返し直後の1画面に入る（ui-refine-home）
- 一覧の1行は1行に収める。折り返すなら全行で揃える（ui-refine-home）
