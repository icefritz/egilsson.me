# Proposal

## Why

前回の home の change（ui-refine-home）の後も、ホームには次の問題が残っていた。ロケーションメニューの項目が箱ごとに影付きで並ぶ。地点を変える入口が句点だけで、手がかりも当たり判定も小さい。11px と 12px の補助テキストがあり、「Default」だけブランド色の丸いバッジになっている。スマホでは Checklist の行が下端で切れる。天気の見出しが折り返し、「vedur.is」だけが次の行に残る。風速に単位がなく、スマホでは日別の風が消える。

## What Changes

- ロケーションメニューを面1つにし、項目は1pxの罫線で区切る。項目の高さは 44px 以上にする（参考: yr.no の日別一覧。各行はカードにしない）。
- 句点（地点の入口）は、当たり判定だけ広げる（見た目は変えない）。
- 補助テキストを 13px 以上にする（時刻・日付・風・ステーション名・メニューの注記）。
- 「Default」は灰色 13px の「(default)」にする（ブランド色はやめる）。
- スマホでは上下の余白を 24px にし、Checklist の行が画面内に入るようにする。
- 天気の見出しは地点名と観測所だけにし、「Measured 時刻 · vedur.is」を天気カードの最下段に移す。
- 時間別の風に「m/s」を付け、スマホでも日別の風を残す（列を1つ追加）。
- デスクトップでもメニューに面を付け、天気の見出しに重ならないようにする。

データや操作（地点の保存、天気の取得元、メニューで選ぶ動き）は変えない。ナビの配置（F8）は現状のまま。

## Impact

- 変えるファイル: `index.html`（ホーム専用の `<style>`）、`assets/weather.js`（見出し・末尾の描画、風の単位、既定の表示）。
- 影響する他画面: なし（`.wx-`、`.dot` はホームだけで使う）。
- テスト: 静的サイトのためテストはない。見た目は 390×844、360×740、1440×900 と、メニューを開いた状態で確認する。
- 検証: `/ui-review --verify ui-refine-home-2` の Before/After スクショと実機で確認する。
- 参考スクショ: `screenshots/review-home-*.png`（Before）、`screenshots/after-home-*.png`（After）
